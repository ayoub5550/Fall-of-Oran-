# AGENT.md — Fall of Oran (سقوط وهران) — Unreal Engine 5 edition

Documentation for AI agents (and humans) continuing development. Written by Viktor (AI employee)
after porting the game from Godot (v1.4, now in `legacy-godot/`) to **Unreal Engine 5.8.2** (v1.5).
Read fully before touching code. The Godot version is frozen; all new work happens in UE5.

## 1. What this is

Third-person zombie survival-horror slice set in **Oran, Algeria** (RE4-Remake feel: over-the-shoulder
camera, dark rainy street at night, scarce ammo). Target: **Android phone** (arm64, Vulkan / ES3.1).
All player-facing text is **Arabic**. Everything is C++ — no Blueprints; the level is generated in code.

Owner: Ayoub (GitHub `ayoub5550`). Engine: his private fork `ayoub5550/UnrealEngine`, branch
`release`, UE 5.8.2 (see `AI-AGENT-BUILD.md` there for a headless Linux build recipe).
Offline rendering (cinematics etc.) is done on **SheepIt**, never locally — see `RENDERING.md` in the fork.

## 3. Game design (v1.5)

- **Mission**: collect 3 fuel cans → port gate opens → reach it → win. Each fuel pickup calls
  `SpawnZombiesBehindPlayer(2)`.
- **Pickups**: 3 fuel, 3 medkits (+40), 4 ammo boxes (+12) at fixed positions in `SpawnPickups()`.
- **Zombies**: 16 at fixed `Spots[16]` (2200–8800 cm along X), 4 skins, runners on `i % 5 == 2`.
- **HUD** (Arabic): health bar, `12 / 36`, `قتلى N`, `وقود N/3`, objective bar, crosshair, damage flash,
  virtual joysticks, fire button «نار», menu/death/win screens.

## 4. Asset pipeline

- **Characters/anims**: Mixamo (account = owner's Google mail). Hero `hero_swat`; zombies
  `z_war, z_girl, z_cop, z_parasite`. Clips: `z_idle/idle2/walk/walk2/run/attack/attack2/bite/death/death2/
  scream/crawl/standup/hit/hit2`, `h_idle/walk/run/strafe_l/strafe_r/back/shoot/shoot2/reload/hit/death/
  death2/injured_walk/injured_idle/idle_relaxed`. Export "With Skin" for the character, "Without Skin" for
  clips, FBX binary. Imported via Interchange in `Tools/import_assets.py`; skeleton shared per character.
- **Props**: Quaternius packs, FBX → imported with `combine_static_meshes_behavior = ALL`.
- **Audio**: Sonniss GDC bundles (royalty-free), picked WAVs in `RawAssets/Audio/` → `/Game/Audio/*`.
- **Font**: Debian's Noto Kufi Arabic is stripped of Latin; `Content/Fonts/FOKufi.ttf` = NotoKufiArabic
  merged with NotoSans ASCII (fontTools). Do not import as UFont (crashes headless) — load the raw TTF.

## 5. Building (Linux, headless, no GPU needed)

```
UE=/path/to/UnrealEngine
# editor target (needed for cooking)
$UE/Engine/Build/BatchFiles/Linux/Build.sh FallOfOranEditor Linux Development -project=$PWD/FallOfOran.uproject
# import assets (only after changing RawAssets)
$UE/Engine/Binaries/Linux/UnrealEditor-Cmd $PWD/FallOfOran.uproject -run=pythonscript \
  -script=$PWD/Tools/import_assets.py -nullrhi -unattended -nopause -nosplash -stdout -ddc=NoZenLocalFallback
# Android APK (JDK 17, SDK platform 36, build-tools 36.1.0, NDK r27; paths in DefaultEngine.ini AndroidSDKSettings)
$UE/Engine/Build/BatchFiles/RunUAT.sh BuildCookRun -project=$PWD/FallOfOran.uproject -platform=Android \
  -cookflavor=ASTC -clientconfig=Development -build -cook -stage -package -pak -archive \
  -archivedirectory=out -nop4 -utf8output -unattended -NoUBA -ddc=NoZenLocalFallback
```
Output: `out/Android_ASTC/FallOfOran-arm64.apk` (~166 MB, data inside APK). Package
`com.ayoub5550.falloforan`, minSdk 26, targetSdk 34.

## 6. Testing & pitfalls

- Logic smoke test: run the game with `-nullrhi -game`; look for `LogFO: Street built: N components`.
- Automated shots: `-FOShots` flag (GameMode `bShotMode`, `TickShots()` cycles 5 views and saves PNGs).
  On a CPU Vulkan driver (lavapipe) UE needs `-AllowCPUDevices`; the ES3.1 path renders the HUD but the
  3D world stays black (missing `VK_KHR_dynamic_rendering_local_read`), SM5 asserts on texture formats.
  **Real gameplay screenshots must come from a phone.**
- `-ExecCmds="quit"` does not quit a cooked game; kill the process.
- Static components must be created before `RegisterComponent` in `AFOWorldBuilder`.
- Never commit credentials; `SecurityToken` in DefaultEngine.ini is auto-regenerated by the editor.
