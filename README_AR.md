# وهران: السقوط — Oran: The Fall (v1.0)

## طريقة الفتح على الهاتف
1. فك ضغط هذا الملف.
2. افتح Godot 4 ← Import ← اختر ملف `project.godot`.
3. اضغط تشغيل ▶️ (أول تشغيل يأخذ دقيقة لاستيراد الخامات)

## التحكم
- النصف الأيسر: جويستيك للحركة
- النصف الأيمن: اسحب لتدوير الكاميرا
- زر «نار» أسفل اليمين: إطلاق النار (تعبئة تلقائية)

## المهمة
اجمع 3 عبوات وقود ⛽ متوهجة لفتح بوابة الميناء ثم اهرب.
- علب حمراء = صحة ❤️
- علب خضراء = ذخيرة 🔫
- الزومبي يموت بـ 3 طلقات — واحذر الزاحفين على الأرض!
